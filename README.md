# Kasisite website

Static site for https://kasisite.co.za. Hosted on GitHub Pages, with Cloudflare in front.

## Put it online

1. Create a new GitHub repository and upload everything in this folder to the root of the `main` branch.
2. In the repository go to Settings > Pages. Set the source to "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Register `kasisite.co.za`. The `CNAME` file already contains the domain. In Pages, enter the custom domain and tick "Enforce HTTPS" once it becomes available.
4. In Cloudflare, add these DNS records for `kasisite.co.za`:
   - Four A records on the root name (`@`) pointing to `185.199.108.153`, `185.199.109.153`, `185.199.110.153` and `185.199.111.153`.
   - One CNAME record for `www` pointing to `<your-github-username>.github.io`.
5. In Cloudflare set SSL/TLS mode to "Full", turn on "Always Use HTTPS", and add a redirect rule from `www.kasisite.co.za` to `https://kasisite.co.za`.
6. Open Google Search Console, add the domain, and submit `https://kasisite.co.za/sitemap.xml`.

## After launch

- Create the Google Business Profile as a service-area business with the address hidden, and use the same name and phone number as the website.
- Add a small "Website by Kasisite" link to the footer of every client site. It is a free, honest backlink.
- Ask each client for a Google review after their site goes live. Show only real reviews on the site.
- Replace the simplified phone previews on the home page and the two case study pages with real screenshots of the live sites when you have them.

## Add a blog post

1. Open `tools/posts.py` and add a new entry at the top of the `POSTS` list (title, slug, description, date, body).
2. Run `python3 tools/build.py`. It rebuilds every page, the blog index, `sitemap.xml` and `llms.txt`.
3. Commit and push.

## Change prices, wording or pages

All pages are generated by `tools/build.py`. Edit the text there, run `python3 tools/build.py`, then commit. Colours and layout are in `assets/css/style.css`. `tools/make_images.py` re-creates the logo and social share image.
